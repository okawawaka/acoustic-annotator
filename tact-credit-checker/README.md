# TACT Credit Checker（学修要覧・単位要件チェッカー） 🎓

> 東海国立大学機構（名古屋大学・岐阜大学等）の学修支援システム「**TACT**」（Sakai CLE）の講義データから、大学生の履修状況・卒業必要単位を自動判定・個別管理するブラウザ拡張機能（Chrome Extension Manifest V3）。

---

## 🌟 主な特徴

1. **TACTから全講義をワンクリックで一括取得（ページネーション対応）**
   - TACTにログインした状態で「TACTと同期」ボタンを押すだけで、受講中および過去のすべての講義（10件制限なく全件）をDirect API（`/direct/site.json`）経由で一括取得します。
2. **TACT / Sakai CLE に馴染む端正な公式風UI**
   - 派手なグラデーションや無駄な装飾を排し、TACT公式・名古屋大学のトーン＆マナー（TACTディープネイビー `#19365c`、端正な表形式）に完全調和した実用的なデザインです。
3. **名古屋大学の『学修要覧（履修の手引）』『学生便覧』に準拠した単位配当表**
   - 名大の全9学部（文学部・教育・法・経・情報・理・医・工・農）の標準枠組みを搭載。
   - 一般論で固定するのではなく、**入学年度・専攻（学科・系）ごとに異なる単位数・条件をご自身の学生便覧を見ながら1単位単位で自由に照合・編集・保存**できます。
4. **個別の科目精査・区分割り当てサポート**
   - TACTから取得した全科目を一覧表で確認でき、各科目の「配当区分」「単位数（1/2/4/6単位等）」「状況（履修中/修得済/不可/免除）」を1科目ずつ確実に設定・調整できます。
5. **完全ローカル完結・安心のプライバシー設計**
   - すべてのデータはブラウザ内部（`chrome.storage.local`）にのみ保存され、外部サーバーへの通信は一切行われません。

---

## 🚀 インストール & 更新手順

1. 本リポジトリの `tact-credit-checker` ディレクトリを準備します。
2. ブラウザで `chrome://extensions`（または `edge://extensions`）を開きます。
3. 画面右上の **「デベロッパーモード」** をオンにします。
4. **「パッケージ化されていない拡張機能を読み込む」** で `tact-credit-checker` を選択します。（すでに読み込み済みの場合は更新アイコン 🔄 をクリック）

---

## 📖 使い方

### 1. TACTと同期
1. ブラウザで [TACT (https://tact.ac.thers.ac.jp)](https://tact.ac.thers.ac.jp) を開き、普段通りログインしたタブを開きます。
2. 拡張機能のアイコンまたはダッシュボードから **「🔄 TACTと同期」** を押すと、受講中・過去の全講義が一括取得されます。

### 2. 単位配当表（学生便覧）の照合・確認
- **「📊 卒業要件・単位配当表」** タブで、全学教育科目・専門教育科目の小計および総計、各区分の充足・不足（「✓ 充足」「あと ○ 単位」）を確認できます。
- 各区分の行をクリックすると、その区分に算入されている科目一覧が展開されます。

### 3. 科目の個別精査・区分変更
- **「📑 履修科目一覧・個別精査」** タブで、各講義が手引きのどの区分に該当するかをプルダウンで変更できます。単位数や状況（履修中・修得済）も即座に切り替え可能で、リアルタイムに単位集計へ反映されます。

### 4. 学修要覧・手引き設定のカスタマイズ
- **「⚙️ 学修要覧・要件設定シート」** タブで、入学年度や学部・専攻テンプレートを選択し、お手元の学生便覧に記載されている必要単位数や履修条件メモを直接キーボードで編集・保存できます。
