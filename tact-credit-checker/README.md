# TACT Credit Checker 🎓

> 東海国立大学機構（名古屋大学・岐阜大学等）の学修支援システム「**TACT**」（Sakai CLE）の講義データから、大学生の履修状況・卒業要件単位を自動判定・個別管理するブラウザ拡張機能（Chrome Extension Manifest V3）。

## 🌟 主な特徴

1. **TACTから全講義をワンクリックで一括取得（ページネーション対応）**
   - TACTにログインした状態で「TACTと同期」ボタンを押すだけで、受講中および過去のすべての講義（ページ制限なく全件）をDirect API（`/direct/site.json`）経由で一括取得します。
2. **単位対象外サイトの自動除外フィルタ**
   - お知らせ、ハラスメント防止e-Learning、学生支援本部、検定試験手続き等の単位に含まれないサイトを自動判別し、単位計算から確実に除外します。
3. **名古屋大学文学部（22専修・全124単位）公式履修要覧完全準拠**
   - 全学教育科目（40単位）＋専門基礎科目（2単位）＋共通基盤（2単位）＋共通実践（3単位）＋専攻専門（32単位）＋卒業論文（10単位）＋専攻外選択（35単位）＝ **計124単位** を完全モデル化。
   - 人文学入門・共通基盤・共通実践・専攻専門科目の超過単位は「専攻外選択科目（35単位）」へ自動振替算入されます（※全学教育科目の超過分は厳格に除外）。
4. **TACT / Sakai CLE に馴染む端正な公式風UI**
   - 派手なグラデーションや無駄な装飾を排し、TACT公式・名古屋大学のトーン＆マナー（TACTディープネイビー `#19365c`、端正な表形式）に完全調和した実用的なデザインです。
5. **個別の科目精査・区分割り当てサポート**
   - TACTから取得した全科目を一覧表で確認でき、各科目の「配当区分」「単位数（1/2/4/6単位等）」「状況（履修中/修得済/不可/免除）」を1科目ずつ確実に設定・調整できます。
6. **完全ローカル完結・安心のプライバシー設計**
   - すべてのデータはブラウザ内部（`chrome.storage.local`）にのみ保存され、外部サーバーへの通信は一切行われません。

## 🚀 インストール & 読み込み手順

### Chrome / Edge の場合
1. 本リポジトリをクローンまたはZIPダウンロードして展開します。
   ```bash
   git clone https://github.com/okawawaka/tact-credit-check.git
   ```
2. ブラウザで `chrome://extensions`（Edgeの場合は `edge://extensions`）を開きます。
3. 画面右上の **「デベロッパーモード」** をオンにします。
4. **「パッケージ化されていない拡張機能を読み込む」** をクリックし、本フォルダを選択します。
5. ブラウザのツールバーにアイコンが表示されます。

## 📖 使い方

### 1. TACTと同期
1. ブラウザで [TACT (https://tact.ac.thers.ac.jp)](https://tact.ac.thers.ac.jp) を開き、通常通りログインしたタブを開きます。
2. 拡張機能のアイコンまたはダッシュボードから **「🔄 TACTと同期」** を押すと、受講中・過去の全講義が一括取得されます。

### 2. 単位配当表（学生便覧）の照合・確認
- **「📊 卒業要件・単位配当表」** タブで、各区分の充足・不足（「✓ 充足」「あと ○ 単位」）を確認できます。
- 各区分の行をクリックすると、その区分に算入されている科目一覧が展開されます。
- 超過振替が発生した区分には「`✓ 充足 (+N超過振替)`」が表示され、選択科目カードに「`🔄 超過振替算入: +N単位`」が表示されます。

### 3. 科目の個別精査・区分変更
- **「📑 履修科目一覧・個別精査」** タブで、各講義が手引きのどの区分に該当するかをプルダウンで変更できます。単位数や状況（履修中・修得済）も即座に切り替え可能です。

### 4. 学修要覧・手引き設定のカスタマイズ
- **「⚙️ 学修要覧・要件設定シート」** タブで、入学年度や学部・所属専攻を選択し、お手元の学生便覧に記載されている必要単位数や履修条件メモを直接編集・保存できます。

### 検証項目 (110項目)
- 全22専修の124単位整合性ループテスト
- B表科目（教養教育院）と文学部専門科目の厳格な分離判定
- 単位対象外サイト（お知らせ、e-Learning、学生支援等）の完全除外
- 超過単位の35単位選択科目への自動振替（全学教育科目の超過分が厳格に除外されること）
- Unicode NFKC正規化による表記揺れ（全角半角・ローマ数字）吸収
