# TACT Credit Checker 🎓

> 東海国立大学機構（名古屋大学・岐阜大学等）の学修支援システム「**TACT**」（Sakai CLE）の講義データから、大学生の履修状況・卒業必要単位を自動判定・可視化するブラウザ拡張機能（Chrome Extension Manifest V3）。

---

## 🌟 主な特徴

1. **ワンクリックでTACTから履修講義を取得**
   - TACTにログインした状態で「TACTと同期」ボタンを押すだけで、Sakai内部Direct REST API（`/direct/site.json`）を経由して受講中および過去の講義一覧を一括取得します。
2. **卒業要件の達成度を直感的に可視化**
   - 全体必要単位数（例: 124単位）に対する「修得済単位」「履修中単位」「残り必要単位」をプログレスバーと円環ゲージで一目で把握できます。
   - 区分別（基礎セミナー、言語文化、文系教養、理系基礎、専門必修、専門選択など）の充足・不足アラートをリアルタイム表示。
3. **科目名・コードからのインテリジェント自動分類**
   - 講義名から外国語科目、基礎セミナー、専門科目、実験実習科目などを自動判別し、標準単位数（2単位/1単位/卒論単位等）を推測します。
4. **インタラクティブなかんばん振分ボード**
   - カードをドラッグ＆ドロップして区分を自由に移動可能。移動した振り分けパターンは自動学習され、次回以降の同期時にも保持されます。
   - 単位数（1/2/4/6単位）や履修ステータス（修得済 / 履修中 / 不可 / 免除）をワンクリックで切り替え。
5. **学修要覧（履修の手引き）に合わせた柔軟なカスタマイズ**
   - 名古屋大学各学部（文学部、情報学部、工学部等）および汎用大学のプリセットテンプレートを標準搭載。
   - 区分名の変更、必要単位数の微調整、新しい区分の追加などをGUI上で自由に行えます。
6. **完全ローカル完結・安心のプライバシー設計**
   - 履修データや成績データはすべてブラウザ内部（`chrome.storage.local`）にのみ保存されます。外部サーバーへの送信・トラッキングは一切ありません。
7. **JSON / CSV エクスポート・インポート対応**
   - 履修計画や単位計算結果をCSV（Excel互換）やJSONファイルとして書き出し・復元できます。

## 🚀 インストール手順 (Chrome / Edge / Brave 等)

1. 本リポジトリをダウンロードまたはクローンします。
2. ブラウザで拡張機能管理ページを開きます。
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. 画面右上の **「デベロッパーモード」** をオンにします。
4. **「パッケージ化されていない拡張機能を読み込む」**（Load unpacked）をクリックします。
5. 本フォルダ内の `tact-credit-checker` ディレクトリを選択します。
6. ブラウザのツールバーに「🎓 TACT Credit Checker」アイコンが表示されれば導入完了です！

## 📖 使い方

### 1. TACTと同期する場合
1. ブラウザで [TACT (https://tact.ac.jp)](https://tact.ac.jp) を開き、普段通り機構アカウントでログインします。
2. TACT画面の右下に表示される **「🎓 単位チェッカー」** ボタン、またはブラウザ右上の拡張機能アイコンをクリックします。
3. **「🔄 TACTと同期」** をクリックすると、受講中・過去の講義データが自動で読み込まれます。

### 2. オフライン・動作体験（サンプルデータ）
- TACTにアクセスできない環境や開発・デモ時には、ダッシュボードの **「✨ サンプル読込」** ボタンを押すことで、名古屋大学の模擬履修データ（16科目）を使って即座に操作感を試すことができます。

### 3. ダッシュボードでの操作
- **区分の移動**: 科目カードを目的の区分カラムへドラッグ＆ドロップします。
- **単位数変更**: カード上の「2単位」バッジをクリックすると、1 ➜ 2 ➜ 4 ➜ 6 ➜ 1 と順に切り替わります。
- **ステータス変更**: 「修得済」「履修中」バッジをクリックすると、履修中 ➜ 修得済 ➜ 不可 ➜ 免除 とステータスが切り替わります。
- **要件のカスタマイズ**: 上部メニューの **「⚙️ 要件設定」** から、所属学部の学修要覧に合わせて各区分の必要単位数を変更できます。

## 🔒 セキュリティ & プライバシー

本拡張機能は、学内LMS（TACT）との通信においてブラウザ既存の認証Cookieを利用し、取得したデータはユーザーの端末内にのみ保持されます。詳細は [PRIVACY.md](./PRIVACY.md) をご確認ください。
