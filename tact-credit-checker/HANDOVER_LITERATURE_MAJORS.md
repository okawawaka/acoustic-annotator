# 名古屋大学文学部 卒業要件単位定義 追加・更新引き継ぎ書

本ドキュメントは、名古屋大学文学部（全22専修）において、言語学専修に続いて残り21専修の詳細な卒業要件区分・開講科目リストをシステムへ追加・反映するための引き継ぎ書です。

---

## 1. 文学部卒業要件の共通骨格（124単位ルール）

全22専修共通で以下の **124単位** 構成となっています。

| 大区分 | 中区分 | 単位数 | 備考・振替ルール |
| :--- | :--- | :---: | :--- |
| **全学教育科目** | 基礎科目群 (36) + 総合科目群 (4) | **40** | 進級要件36単位。<br>※**超過分は選択科目(35単位)には絶対に算入されません**。 |
| **専門系科目** | 専門基礎科目（人文学入門Ⅰ〜Ⅳ） | **2** | 進級要件2単位。<br>★**2単位を超える分は「専攻外選択科目(35単位)」へ自動振替**。 |
| **専門科目** | 全専修共通科目（共通基盤2 + 共通実践3） | **5** | ★**5単位を超える分は「専攻外選択科目(35単位)」へ自動振替**。 |
| **専門科目** | **専攻に関係のある科目** | **32** | **専修ごとに内訳・必要単位数が変化**（本引き継ぎの対象）。<br>★**32単位を超える分は「専攻外選択科目(35単位)」へ自動振替**。 |
| **専門科目** | 卒業論文 | **10** | 4年次必修（論文審査合格要件・TACT連携外トグル）。 |
| **専門科目** | **専攻外選択科目** (`dept_free`) | **35** | ①人文学入門超過分、②共通基盤・実践超過分、③専攻専門超過分、④文学部他専修科目、⑤他学部履修科目が算入される。 |
| **合計** | | **124** | **40 + 2 + 5 + 32 + 10 + 35 = 124単位** |

## 2. ユーザー向け：情報提示フォーマット（テンプレート）

ユーザーが新しい専修の要件を提示する際は、以下のMarkdownテンプレートに沿って記載してください。

```markdown
# [専修名]（例: 日本史学専修）
## 概論系科目（必要単位: 4）
- 日本史学概論a
- 日本史学概論b

## 講義系科目（必要単位: 14）
- 日本古代史講義
- 日本中世史講義
- 日本近世史講義
- 日本近現代史講義
- 日本文化史講義

## 語学系科目（必要単位: 0）
※語学系が不要な専修は 0 と記載してください。単位は講義系などに振り分けられます。

## 入門演習系科目（必要単位: 4）
- 日本史学入門演習a
- 日本史学入門演習b

## 調査・実習系科目（必要単位: 0）
※考古学・地理学・社会学・心理学など、実習科目がある専修のみ記載（なければ0）。

## 演習系科目（必要単位: 8）
- 日本古代史演習Ⅰ
- 日本古代史演習Ⅱ
- 古文書学演習
- 日本史史料講読

## 卒業論文演習（必要単位: 2）
- 日本史学卒業論文演習a
- 日本史学卒業論文演習b
```
※各区分の必要単位数の合計が **ちょうど32単位** になることを確認してください。

### 手順1: `presets.js` の `LIT_DEPARTMENTS` を更新
`presets.js` には既にモジュール化された `createDepartmentPreset` ヘルパーが実装されています。  
該当専修のオブジェクトを以下のように書き換えてください。

```javascript
createDepartmentPreset({
  id: "japanese_history",            // 専修ID
  name: "日本史学専修",               // 専修名
  facultyGroup: "歴史文化学繫",       // 学繫
  surveyCredits: 4,                  // 概論系単位数
  lectureCredits: 14,                // 講義系単位数
  languageCredits: 0,                // 語学系単位数（不要なら0）
  introSeminarCredits: 4,            // 入門演習系単位数
  practiceCredits: 0,                // 実習系単位数（なければ0）
  seminarCredits: 8,                 // 演習系単位数
  thesisSeminarCredits: 2,           // 卒論演習単位数
  // ※合計: 4 + 14 + 0 + 4 + 0 + 8 + 2 = 32単位
  courses: {
    survey: ["日本史学概論a", "日本史学概論b"],
    surveyKeywords: ["日本史学概論", "日本史概論"],
    lecture: [
      "日本古代史講義", "日本中世史講義", "日本近世史講義", "日本近現代史講義"
    ],
    lectureKeywords: ["日本史講義", "古代史", "中世史", "近世史", "近現代史"],
    introSeminar: ["日本史学入門演習a", "日本史学入門演習b"],
    introSeminarKeywords: ["日本史学入門演習"],
    seminar: [
      "日本古代史演習Ⅰ", "日本古代史演習Ⅱ", "古文書学演習"
    ],
    seminarKeywords: ["日本史学演習", "古文書学", "日本史史料講読"],
    thesisSeminar: ["日本史学卒業論文演習a", "日本史学卒業論文演習b"],
    thesisSeminarKeywords: ["日本史学卒業論文演習", "日本史学卒論演習"]
  }
})
```

> [!TIP]
> **表記揺れ対策**:  
> `courses` 配列には全角・半角（例: `Ⅰ`, `I`, `1` / `ａ`, `a` / `A`）を両方登録しておくと、TACT上の講義タイトルがどちらであっても100%自動認識されます。

### 手順2: 単位計算エンジン（`parser.js`）の動作
`parser.js` は今回の改修で**完全動的ディスパッチ**になっています。
- `cat.courseList` による完全一致・部分一致
- `cat.keywords` によるキーワード一致
- 文学部専門科目（`origin === "faculty"`）で自専修のどの区分にも一致しなかった場合は自動的に `dept_free`（専攻外選択科目 35単位）へフォールバック
- 人文学入門（2単位）、共通基盤・共通実践（5単位）、専攻専門（32単位）の超過分は自動的に `dept_free` へ合算
- 全学教育科目（40単位）の超過分は厳格に除外
したがって、**`parser.js` や `dashboard.js` のコードを修正する必要はありません**。`presets.js` のデータ追加だけで自動的に連動します。

### 手順3: 自動テストの実行
修正後、以下のコマンドで整合性を検証してください。

```powershell
node tact-credit-checker/test.js
```

全専修（22専修）の合計が 124 単位になっていること、および科目マッピングと超過振替が正常に動作していることが自動検証されます。
